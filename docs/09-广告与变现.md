## 二、四个广告位

| `AdTag` | 值 | 语义 | 状态 |
|---|---|---|---|
| `CARRY_OVER` | `carry_over` | 同关复玩继承（更高难度首次进入免费继承） | ✅ 已有业务入口 |
| `CRYSTAL` | `crystal` | 补许愿水晶 | ✅ 有完整设计 |
| `REVIVE` | `revive` | 战败后保留成长与波次继续 | ✅ 战败面板已调用，真实广告未验收 |
| `DOUBLE_REWARD` | `double_reward` | 结算双倍奖励 | 🔴 **无设计文档、无调用方** |

`REVIVE` 当前调用链：DefeatPanel → LevelFlow.reviveDefeated() → AdReward.show(REVIVE)。所有关卡战败均可自选；完整观看后按当前成长满血重建战场，保留装备、奖励去重及波次进度，存活敌人满血重建，不恢复坐标/弹道/冷却。广告失败或未完成保持 DEFEAT，可继续选择免费重试或退出。没有接入真实广告位前，只能认定本地流程和模拟结果。

## 三、三条不可让步的约束（这是这套变现设计最大的优点）

### 3.1 没有任何成长动作必须看广告

```ts
// GachaConfig.ts / ForgeManager.ts —— 所有 Manager 函数都不接收广告参数
```

从**接口上**就不可能做出强制。广告只有几个"加速"入口：
`grantCrystalByAd()` / `grantStoneByAd()` / 祝福值 +3。

素材必须全是**免费路径**，广告至多是"看完提前拿到"。
这是提审时最重要的一条护栏。

### 3.2 广告的位置要放在"玩家已有明确动机"的地方

| 位置 | 动机 | 合理性 |
|---|---|---|
| `CARRY_OVER` 复玩继承 | "我要冲纪录" | ✅ 强动机，且**失败也无损失**（"重新开始"不删档） |
| `CRYSTAL` 补水晶 | "我想快点抽到那把" | ✅ 纯加速，不影响通关 |
| 祝福值 +3 | "我愿意为概率付费" | ✅ 只加成概率，不直接给装备 |

**明确不做的事**：

- ❌ 首次进更高难度做成广告位 —— 把游戏机制做成门槛会被判定**强制观看广告**
- ❌ 材料必须看广告才能拿
- ❌ 卡关时强制看广告才能继续 —— 见 [07-存档与继承 §6](07-存档与继承.md) 的三条理由

### 3.3 失败也无损失

`AdReward.show()` 只有 `isEnded === true` 才算成功。失败/取消不发任何惩罚，
玩家仍可走"重新开始"路径（且档案保留）。

## 五、🔴 变现缺口（上线阻塞项）

### 5.1 只有激励视频一条腿

微信小游戏的合理变现组合是：

| 形式 | 当前状态 |
|---|---|
| **激励视频** | 有 4 个标签；继承、水晶和复活已接业务，双倍奖励仍未接入；广告 ID 均待配置 |
| **插屏广告** | 🔴 **完全没有** |
| **Banner 横幅** | 🔴 **完全没有** |
| **激励视频插件 / 互斥流量** | 🔴 没有 |

只有激励视频意味着 eCPM 单一、无法做高频曝光，
推广买量后的 ROI 会很难跑正。**这是变现侧最大的缺口。**

### 5.2 双倍奖励仍缺触发与奖励规则

复活规则已按本节前面的当前实现接入；其真实广告行为和频控待专项验证。双倍奖励仍缺：

- **双倍奖励** —— 是金币双倍还是水晶双倍？两者价值差 10 倍，定价完全不同。
  是否与复玩加难叠加？

### 5.3 频控策略缺失

四个位如果都按"每次触发都给"，会遇到：

- 复玩继承反复点 → `CARRY_OVER` 曝光量可能很高，但用户疲劳也快
- 广告疲劳度没有下降曲线

文档里没有"每局最多看 N 次""每类广告的最小间隔"这类频控设计。

## 七、变现策略建议与实施现状

以下是基于现有代码结构可落地的最小方案，供拍板：

### 7.1 接入插屏

- **触发点**：关卡结算页（`SETTLE`）之后、返回选关时
- **频控**：每 N 局一次（建议 N = 3），同一局只弹一次
- **不受影响**：新手引导期间、首次通关前 3 局、复活流程中一律不弹

结算页是天然的高频位置，且玩家此时心态是"刚才打完了"，干扰最小。

### 7.2 接入 Banner

- **位置**：选关界面底部或结算页
- **注意**：Banner 会占屏幕空间，而战斗是拖动走位玩法，
  **战斗层内绝不能放 Banner**（会挡手指）

### 7.3 双倍奖励建议与复活现状

| 位 | 建议触发 | 建议收益 | 理由 |
|---|---|---|---|
| `REVIVE` | 已实现：任意关卡战败，玩家自选 | 满血重建战场，保留波次与成长；辅助和武器保留 | 当前规则，非原地完整快照恢复 |
| `DOUBLE_REWARD` | 结算页，`SETTLE` 阶段 | 金币 ×2（**不要给水晶**） | 水晶 10 = 1 抽，翻倍相当于白送 5 抽，冲击太大 |

### 7.4 建议补的频控常量

```ts
// 建议新增到 ad/AdReward.ts
const MAX_CARRY_PER_SESSION = 5;    // 单次游戏会话最多看几次继承广告

const INTERSTITIAL_MIN_AFTER_LEVEL = 3;   // 前 3 关不弹插屏
```
