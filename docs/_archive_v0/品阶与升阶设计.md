# 品阶与升阶设计（第八轮）

> 需求原文：
> "关于武器升级加一个武器的材料, 就是比如任意一个武器升级, 需要从0 到加一加二,
>  然后升阶时候加一个同阶武器到两个同阶武器甚至根据阶级不同数量不同,
>  但是数量上不要太过于卡, 在升阶后属性要比升阶前强度有明显提升,
>  然后抽奖方面, 可以抽到材料, 以及直接兑换高阶的随机碎片, 25个碎片换高阶武器, 武器种类支持任选,
>  再加装备池, 装备池只抽装备, 默认抽低的装备, 但是有概率直接抽到高的装备, 也有碎片,
>  碎片可以换任意装备, 辅助池也一样, 武器方面再提供一些初始就是高阶类型的,
>  目前装备品阶我没沟通, 不知道定了吗, 没定的话就是, 青铜 白银 黄金 钻石 史诗 神话 传说
>  关于从钻石往上, 每个阶级都有直接是那个阶级的装备, 抽奖最高抽到神话级,
>  传说这个阶级的都是从神话进化来的, 添加专属进化神话的材料, 这个材料在后面复合关卡才会出,
>  三复合的关卡才会出, 并且只有噩梦难度才出, 概率度, 你来定,
>  但是添加一个看广告可以提高概率的功能, 不看也可以, 可以献祭水晶来提高概率,
>  就是不抽, 直接献祭水晶, 具体概率转换你来定,
>  每个等阶的装备, 钻石往上等阶的专属装备都是自带复合属性加成的, 不管是武器还是防具,
>  一个是自带的属性, 一个是材料加进去的属性, 升阶会继承属性, 然后可以继续添加属性石头, 来加强属性效果"

这一轮给游戏补上了**装备的品质轴**，并把抽卡从一个"随机给东西"的系统
变成了有结构、有保底、有确定路径的收集系统。

---

## 一、七阶品阶

| 阶 | 名称 | 强度倍率 | 镶嵌槽 | 升阶消耗同阶装备 | 升阶金币 | 自带复合属性 |
|---|---|---|---|---|---|---|
| 0 | 青铜 | ×1.00 | 1 | 1 | 400 | — |
| 1 | 白银 | ×1.18 | 1 | 1 | 900 | — |
| 2 | 黄金 | ×1.40 | 2 | 2 | 2000 | — |
| 3 | 钻石 | ×1.70 | 2 | 2 | 4500 | ✓ |
| 4 | 史诗 | ×2.10 | 3 | 2 | 9000 | ✓ |
| 5 | 神话 | ×2.60 | 3 | 1 + 专属材料 | 18000 | ✓ |
| 6 | 传说 | ×3.30 | 4 | — | — | ✓ |

**抽奖最高抽到神话（阶 5）**，传说只能由神话进化而来。

### 品阶与局外等级是两条正交的轴

- **局外等级** `level` 1~5：用**金币 + 材料**升级，决定基础数值
- **品阶** `rarity` 0~6：用**同阶装备 + 金币**升阶，决定品质倍率 + 镶嵌槽 + 自带属性

两条轴都必须投入才有满强度装备。这与第四轮"没有任何单一路线能点满无视克制"是同一条原则：
让玩家始终有"还差一点"的具体目标。

### 为什么品阶要替代 forge.rank

第四轮做过一套 `forge.rank`（1~5），唯一作用是决定镶嵌槽位数。
现在品阶也要决定槽位数 —— 两套阶梯并存会让玩家面对
"我要先突破还是先升阶"这种没有意义的问题。

所以品阶**吸收** forge.rank 的职责，`forge.rank` 整套删除，
存档迁移时把老 rank 映射成品阶（见第五节）。

### 倍率曲线为什么前缓后陡

```
青铜 1.00 → 白银 1.18 → 黄金 1.40 → 钻石 1.70 → 史诗 2.10 → 神话 2.60 → 传说 3.30
```

- 前两阶几乎白给（+18%），让玩家立刻尝到升阶的甜头
- 黄金→钻石出现明显断层（1.40 → 1.70），这是"高阶装备"的体感门槛
- 神话→传说只此一条路（专属材料），所以给最大的单跳（+27%）

终局 3.30 倍 ≈ 一件满级局外装备的两倍半，配合 4 个镶嵌槽与自带属性，
传说装备是"一个 build 的核心"，而不是"比神话好一点的装备"。

## 二、武器升级：加入材料消耗

局外升级（`level` 1→5）现在除了金币，还要消耗该武器类型的突破材料 `mat_<type>`。

- 不增加新的货币或背包，复用第四轮的材料体系
- 让"打关卡掉材料"与"升级武器"直接挂钩，而不是只与升阶挂钩

---

## 三、升阶：消耗同阶装备

```
ascendWeapon('blade')
  → 找同品阶的装备当燃料（同 id 优先、等级低的优先）
  → 扣金币
  → 品阶 +1，镶嵌槽跟着长
```

### 件数曲线：1 / 1 / 2 / 2 / 2 / 1（+专属材料）

刻意**不卡**（玩家原话"数量上不要太过于卡"）：
前两阶各 1 件几乎白给；中段固定 2 件，是"要攒一下但不用刷很久"的量级；
神话→传说回到 1 件，因为那一阶的门槛在**专属材料**而不在件数。
**没有一阶超过 2 件。**

### 为什么燃料是装备而不是材料

抽卡抽到重复武器不再只能换 2 个材料 —— 它能当燃料把主力推上白银。
于是"抽重复"从纯亏损变成了有方向的积累，**这是抽卡系统能长期成立的关键**。

### 两个实现细节（都是踩过的坑）

1. **燃料排除必须按对象引用，不能按 id**
   同 id 的重复件恰恰是最主要的燃料来源。若按 id 排除，
   会出现"有两把铁剑却提示燃料不足 0"——因为两把都被当成了升阶目标而跳过。

2. **优先烧低等级的那把**
   如果随机挑燃料，玩家可能眼睁睁看着自己升到 4 级的铁剑被拿去当材料，
   而背包里躺着一条 1 级的。

## 四、高阶专属装备

钻石及以上每一阶都有**直接以该品阶出生**的专属装备，每阶每类 2 件：

| 类别 | 钻石 | 史诗 | 神话 |
|---|---|---|---|
| 武器 | 星刃、霜寒枪 | 疾风弓、震地锤 | 虚空炮、曜日轮 |
| 防具 | 龙鳞铠、泰坦板甲 | 暗影披风、圣者长袍 | 世界树甲、星冠 |
| 辅助 | 龙心坠、星轨戒指 | 凤凰羽、深渊之眼 | 本源核心、时序齿轮 |

### 三个设计决定

**1. 专属装备没有局内进化线**
常规武器的强度来自"局内形态深度"（depth 0→4 一条长线），
专属武器的强度来自**品阶倍率 + 自带属性 + 镶嵌槽**。
再给它们一条进化线会让 build 出现第三条成长轴 —— 那是复杂度堆叠，不是深度。

**2. 基础伤害与同类型常规武器对齐**
`balance_guard` 的机制模型立刻抓出了第一版数据：
新武器有效预算 1.7~1.9 倍中位数，超区间。修正后与同类型常规武器相同
（星刃 = 铁剑的 8，虚空炮 = 重炮的 18）。
**它们的强度来自品阶，不来自裸数值。**

**3. 专属装备不进关卡推荐池**
它们走抽卡引导（面板上写明适合什么阵型），不占推荐坑位。
硬塞进 `AFFINITY_POOL` 会同时破坏两件事：
推荐/克制的战力平衡（高阶自带属性让天平倒向推荐）、轮转节奏（池子从 4 件涨到 7 件）。

## 五、自带复合属性 vs 材料属性

钻石及以上的专属装备有**两套属性来源**，语义必须分清：

| | 来源 | 升阶继承 | 可卸下 |
|---|---|---|---|
| **自带属性** `innate` | 配置表，装备天生就有 | ✓ 自动继承 | ✗ |
| **材料属性** `sockets` | 玩家自己镶的属性石 | ✓ 自动继承 | ✓ 退还完整材料 |

两者在战斗里都是加值，直接相加，但 UI 上必须分开显示 ——
否则玩家卸下镶嵌后会困惑"为什么属性没归零"。

### 自带属性不乘品阶倍率

自带属性的数值已在配置表里按品阶配好（钻石给 0.12、神话给 0.20），
再乘一次倍率会双重放大。

## 六、神话之核：传说的唯一钥匙

`mat_myth_core`（神话之核）是全游戏**唯一不可替代**的材料 ——
不能金币买、不能碎片换、不能广告拿。

### 掉落条件（严格按需求）

- **关卡属性数 = 3**，即第 9~12 关（`elementsForLevel` 的属性数曲线：1~4 关给 1、5~8 关给 2、9~12 关给 3、13 关起给 4）
- **难度 = 噩梦**

### 概率定 25% 的理由

掉落窗口只有 4 关 × 1 个难度 = 4 种组合，而一次"神话→传说"只要 1 个。

- 定 10% 会让平均耗时翻倍到 10 次，那几关的噩梦并不好打，容易变成劝退
- 定 50% 又太便宜，传说会泛滥
- **25% ≈ 平均 4 次通关拿 1 个**，认真打一个下午能出一个传说

### 升阶到传说的完整账

```
1 件神话装备（燃料）
+ 1 个神话之核（第 9~12 关噩梦，25%）
+ 18000 金币
```

## 七、抽卡三池

| 池 | 内容 | 说明 |
|---|---|---|
| 武器池 | 18 把武器（12 常规 + 6 高阶专属） | 可金币升级、升阶、镶嵌 |
| 辅助池 | 14 件辅助（8 常规 + 6 高阶专属） | 可金币升阶，阶数放大 effect |
| **装备池** | 18 件防具 | 只抽防具；默认低阶，小概率高阶 |

三个池子的**保底进度各自独立**，抽武器不会消耗抽辅助的进度。

### 一次抽卡的三类结果

```
装备   74%   主结果，按品阶权重抽
材料   18%   突破/升级用的专属材料
碎片    8%   高阶碎片，攒 25 个可自选高阶装备
```

材料与碎片让每一次抽卡都有意义：即使这抽是重复装备，也可能顺手给几个材料。

### 品阶权重

```
青铜 46  白银 26  黄金 16  钻石 8  史诗 3  神话 1  传说 0（不可抽）
```

指数衰减，每升一阶权重大约减半。这让"抽到神话"成为值得截图的事（1% ≈ 百抽一件），
但又不至于像 0.1% 那样让人绝望。

## 八、高阶碎片兑换

**25 个碎片 → 任选一件高阶（钻石）装备**，三个池子通用同一份碎片。

它是"抽不到也不被卡死"的保底：纯随机有长尾，碎片让玩家永远有一条确定的路走到高阶。

- 已拥有时再兑换 → 不浪费，按重复件折算
- 池子里不存在的 id → 拒绝

## 九、祝福值：献祭水晶 / 看广告

### 两条来源，都完全可选

| 来源 | 收益 |
|---|---|
| 献祭水晶 | 10 水晶 = 1 点（不抽卡，直接换） |
| 看激励视频 | +3 点 |

### 作用：高阶概率翻倍

每抽消耗 1 点祝福值，使本次**钻石及以上**的权重翻倍：

```
无祝福：青铜 46 / 白银 26 / 黄金 16 / 钻石 8 / 史诗 3 / 神话 1   → 高阶合计 12%
有祝福：高阶权重 ×2，低品阶按比例压缩                     → 高阶合计 24%
```

这是一个能被玩家算清楚、也能被测试断言的明确收益 —— 不是保底，是实打实的概率翻倍。

### 上限 30

不给无限叠，否则高品阶概率会被彻底稀释掉随机性。
**祝福值 0 时游戏完全正常**，它不是必需品，只是加速器。

### 为什么广告只加成"概率"而不是"直接给装备"

与"ForgeManager 不接受广告参数"是同一条约束：
广告只能加速，不能成为任何成长动作的必经之路。

## 十、品阶倍率如何进战斗

### 武器：乘在基础伤害上

```ts
const base = (this.baseDamageOfForm(form.sources) + levelFlatAtk / n) * rarityMul;
```

乘基础伤害而不是最终伤害，意味着它与形态 atkPct、天赋、镶嵌全部是乘算关系，
任何一条线变强都能正确叠加。若乘在最终值上会出现"暴击吃两次倍率"这类难以解释的复合。

### 辅助：阶数与品阶是乘算

```ts
aggregateModifier(loadout, auxRankMulOf, auxRarityMulOf, auxInnateOf)
```

- `auxRankMulOf` 局外阶数（第七轮，花金币升）
- `auxRarityMulOf` 品阶强度倍率（第八轮，抽卡 + 消耗同阶装备升阶）
- `auxInnateOf` 自带复合属性（第八轮，不参与倍率放大）

两轴正交且**乘算**：一件 5 阶 + 神话品阶的辅助，
效果是原值的 2.3（阶）× 2.6（品阶）= 5.98 倍。

### 防具：软上限压缩

抗性是百分比，裸乘会让高抗性线性爆炸（34% × 3.3 = 112%，完全免伤）。
所以用软上限：

```ts
scaled = base × mul
实际生效 = scaled <= 1 ? scaled : scaled / (1 + scaled)
```

曲线在 `base×mul ≤ 1` 时等于原值（前期无感），超过 1 后趋于 1 但永不达到。
于是再高的抗性也留得出伤害空间，不会出现"穿上传说防具就无敌"。

## 十一、存档 v5 → v6 迁移

新增字段：`equipment[].rarity`、`auxOwned[].rarity`、`armor.owned: OwnedArmor[]`、
`pityArmor`、`fragHigh`、`blessing`、`totalSacrificed`、`totalAscends`。

### 三条原则

1. **老 rank 映射成品阶，不清零**
   `rarity = rank - 1`（rank 1→青铜，rank 5→史诗）。
   老玩家为 rank 投入的材料与金币一笔勾销是最伤玩家的迁移方式。
   语义也对得上：老 rank 越高 = 投入越多 = 品阶越高。

2. **不补到神话/传说**
   凭空映射上去等于跳过整套第八轮内容，与"不白送养成资源"冲突。
   老玩家迁移后最高到史诗，往上仍要自己打三复合噩梦关卡。

3. **镶嵌槽只增不减**
   两套阶梯的槽位表不完全一致（老 rank 5 = 4 槽，史诗 = 3 槽）。
   `forgeOf()` 保证长度只增不减，所以老玩家保底保留原有石头，
   只是暂时不能加新的，升阶之后自然能用上。

### 不白送任何新材料

水晶保留原值、碎片与祝福值从 0 开始、辅助从 seenForms 回填但一律 1 阶。

## 十三、实现过程中抓到的三个 bug

1. **`WEAPON_ROOT_IDS` 漏加新武器**
   它是硬编码列表，同时是 `fillSources()` 的遍历依据。
   漏掉任何一个根形态，那个形态的 `sources` 会停留在 `[]`，基础伤害算不出来。
   形态图自检立刻报"武器形态缺少 sources"，靠这个校验抓出来的。

2. **`findFodder` 按 id 排除燃料**
   导致"有两把铁剑却提示燃料不足 0"——两把都被当成了升阶目标而跳过。
   改为按对象引用排除。

3. **`canCraftArmor` 用 `rarity > 0` 判断持有**
   品阶 0（青铜）是合法品阶，不能拿 0 当"未持有"的哨兵 ——
   结果青铜防具永远可以重复打造，玩家能刷出无数件。
   改为直接数 `owned` 里有没有这个 id。
