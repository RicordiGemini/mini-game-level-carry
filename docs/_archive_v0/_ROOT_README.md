# 闯关小游戏 · 难度分档 + 拖动走位 + 形态进化 + 锻造属性 + 许愿抽卡 + 防具套装 + 复玩继承 + 新手引导（Cocos Creator 3.8 + TypeScript）

一套可直接接入 Cocos Creator 3.8 的完整闯关玩法骨架：战斗层 + 难度体系 + 装备系统 + 防具套装 + 抽卡收集 + 存档继承 + 新手引导/首通教学。

十四句话概括：

1. **难度**：每一关都有三档难度（普通 / 困难 / 噩梦），通关一档解锁下一难度。难度越高，敌人越硬、越多、越凶，**远程怪比例越高（跨档位硬上限 45%）**；难度又反过来开放能力——出战槽位、以及新的武器。
2. **战斗**：拖动走位，攻击方式由武器类型与形态共同决定 —— 铁剑只有前攻击（靠走位对准）、短弓锁定追踪、铁锤朝拖动方向砸、冰晶球自动打最近、回旋轮全屏横扫。五种瞄准方式 + 十种打击形状，一共 12 把常规武器（另有 6 把高阶专属，共 18 把）。
3. **每关最合适的武器都不一样**：每关有一个**阵型**（零散 / 成列 / 扎堆 / 人海），阵型既真的改变刷怪位置，也决定推荐武器名单（伤害 ×1.25、金币 ×1.30）与克制名单（伤害 ×0.80）。同一个阵型内部的推荐名单还会按关卡轮转。
4. **属性**：参考《洛克王国》的 **24 种属性**（普通/火/水/草/电/冰/石/土/机械/翼/武/毒/虫/幽/龙/恶魔/光/萌 + 金属/剑/木/风/空间/时间）。每关有 1~4 种属性，**按 6 组编排**（"这关是五行关"），前单后复合。武器可镶嵌属性材料，克制 ×1.6、被克 ×0.9；一把武器能叠多个，**上限由等阶决定**。**对局角落常驻克制面板**，装备够好可以**无视克制**。
5. **局内三选一**：打怪攒经验升级，弹出**固定三张卡**（武器 / 辅助装备 / 天赋）。武器和辅助各 6 格（复玩 +2 格），天赋不占格、可叠层，是"永不空屏"的保底。**局内候选池是全部 18 把武器** —— 抽卡不会卡住局内成长。
6. **形态图进化**：进化不再是线性链，而是一张图 —— 有分支（单点爆发 / 范围覆盖两条路）、有**双武器合成**（两把并成一把，消耗一个武器格，之后可以立刻补选一件回来）、还有**只有携带老档复玩时才出现**的更上级形态。
7. **复玩继承**：每关每难度通关后各存一份档案。首次进入更高难度默认免费继承；同一难度复玩时可选是否加难以及加难百分比（+15% ~ +120%）。局内加难面板会把每一档的敌人血量/攻击/数量提前算给你看。
8. **许愿抽卡**：每次通关发**许愿水晶**（普通 10 / 困难 30 / 噩梦 100），**10 个水晶抽一次**。**开局只有一把铁剑**，其余全靠抽。**三个池子分开抽**（武器 18 / 辅助 14 / 防具 92 件），保底进度互不干扰（连续 30 次重复必出新品）。一次抽卡可能是**装备（74%）/ 材料（18%）/ 高阶碎片（8%）**。重复件转化为锻造材料或金币，**没有一样是白抽**。抽到的武器是 1 级 —— 抽卡给的是一条可长期培养的线，不是立刻变强。
9. **七阶品阶**：青铜 → 白银 → 黄金 → 钻石 → 史诗 → 神话 → **传说**。抽奖最高到**神话**，**传说只能由神话进化**，钥匙是「神话之核」—— 只在**第 9~12 关（三复合关卡）的噩梦难度**掉落，25% 概率，不能买、不能换、不能看广告拿。钻石及以上每一阶都有**直接以该品阶出生**的专属装备（武器 / 辅助各 2 件 / 阶，防具 3 套 / 阶即 12 件），**自带复合属性**（区别于玩家自己镶的属性石，两者都随升阶继承）。升阶消耗**同阶装备**（1~2 件，刻意不卡）+ 金币，强度倍率 ×1.00 → ×3.30。
10. **祝福值**：献祭水晶（10 换 1 点）或看广告（+3 点），每抽消耗 1 点，使本次**钻石及以上概率从 12% 翻倍到 24%**。上限 30，**0 值时游戏完全正常** —— 广告只能加速，永远不是必经之路。
11. **高阶碎片保底**：25 个碎片**任选**一件高阶装备，三个池子通用同一份碎片。纯随机有长尾，碎片让玩家永远有一条确定的路走到高阶。
12. **防具四部位套装**：武器能"局外升级 → 升阶"，防具补齐了**同一条轴但不重复**——分**头 / 身体 / 裤子 / 鞋子**四个部位，全在防具池里抽，与武器同等的七阶划分。**23 套 × 4 件 = 92 件**（青铜 5 套起步、其余每阶 3 套），套装有**套装属性**（穿 2 件生效、穿满 4 件拉满），每**单件**又有**专属词条**（按套装定位 attack/defense/speed/lifesteal/element 五套模板）。**低阶套装可升到高阶**（不是只能弃旧换新），**升阶 +3 镶嵌孔**，孔位还能用水晶 / 材料开；青铜 5 套故意做多，给玩家"自己加词条"的自由度。抗性按四部位权重分（身体 0.34 / 头 0.30 / 裤 0.20 / 鞋 0.16）。
13. **新手引导 / 首通教学**：首次进游戏播放 **4 步新手引导**（这是什么 → 怎么操作 → 目标与产出 → 开始第 1 关），**14 条首通提示**在每个系统**第一次出现时弹一次**（走位 / 属性克制 / 三选一 / 进化 / 结算 / 装备 / 抽卡 / 锻造 / 防具 / 难度 / 继承 / 复玩 / 成就 / 图鉴）。文案只讲**"现在该做什么"**，看完即走、同一条永不重复（`TutorialManager` 按 id 持久化去重）。
14. **万象线（隐藏的终局养成线）**：防具的**第四条获取途径**，开局**完全不可见**。24 种碎片各攒 10 个 → 在锻造台**合成「全属性石」**，这一刻这条线才**自动浮现**（在此之前玩家不知道它存在）。之后 4 级递进：**碎片之核 → 镜胚 → 万象镜甲 → 万象套**，每级消耗 **1 个全属性石 + 递增金币**（6k / 12k / 24k / 48k，合计 4 石 + 9 万金）。终点一次性授予**四件套「万象套」（全部传说 / 最高阶）**，四件各**铺满 24 轴抗性**（每轴 0.396，总和 9.504 —— 覆盖最广、每轴最薄，且远低于 75% 抗性上限，不给免疫）。它**不进任何卡池**（防具池恒为 92 件），只能靠这条线拿到。

> 战斗层**完全不依赖引擎**，可以在 Node 里跑完整仿真。
> 自动化断言 **1159 项通过（10 个套件）**：品阶升阶 111 + 抽卡 123 + 流程 181 + 形态图 117 + 战斗 104 + 界面 60 + 平衡守卫 53 + 锻造属性 204 + 防具套装 168 + 教学 38。
> 噩梦档专属：远程比例拉到 42%（基础）+ 三种新敌人（精英/突进/冲锋）。
> 另有 4 个探针脚本（逐档推进、站桩对照、阵型适配对照）用于观察难度曲线。
> **没有任何一个成长动作必须看广告**：抽卡货币 100% 靠通关掉落，广告只是提前拿到下一次抽卡的门票、或把高阶概率翻倍。神话之核连广告都换不到。

流程状态机：

> 首次进游戏时，在进入下面这套状态机**之前**先播一次 4 步新手引导（`TutorialManager.needNewbie()` → `TutorialLayer.startNewbie()`），
> 引导最后一页点「开始第 1 关」直接调 `LevelFlow.openLevel(1)` 进入 `DIFFICULTY`/`PLAYING`。
> 引导与首通提示都是**覆盖层**，不占 `LevelFlow` 的 phase —— 战斗态与面板显隐逻辑完全不受影响。

```
                                        │
                                        └──openLevel(id, tier)──┬─ 该难度有档案 → LOADOUT ─┬─ 看广告 ─→ beginEntry()
                                                                │                          └─ 重新开始 → beginEntry()
                                                                ├─ 无档案 + 低难度有档案 ─→ beginEntry()（★ 默认免费继承）
                                                                └─ 都没有 ────────────────→ beginEntry()（初始装备）
beginEntry() ──该难度打通过？──┬─ 是 → REPLAY_BOOST（选加难百分比；面板会列出各档敌人强度）
                                └─ 否 → PLAYING（第一次打进这档难度时不问加难，问了是劝退）
PLAYING ──升级──→ REWARD（三选一；★ 战斗真的冻结，战场留在背后）
   │                  ├─ 选合成 → 立刻再开一次 REWARD（补选一件武器）
   │                  └─ 选其他 → PLAYING
   ├─ 敌人清空 ──→ SETTLE（写该难度档案 + 解锁下一难度 + 发金币 + 判成就）
   └─ 玩家阵亡 ──→ 提示 2.2s ──→ retryLevel()（本局数据与形态进度全部保留）
SETTLE  ──┬─ 挑战本关下一难度（默认继承装备，无需广告）
          ├─ 进入下一关（新关卡只有普通难度）
          ├─ 加难 +15% 再来一局
          ├─ 看广告带装备重刷本难度
          └─ 返回关卡选择 → SELECT
```

| 金币产出 × | 1.0 | 1.8 | 3.0 |
| 得分 × | 1.0 | 1.5 | 2.2 |
| 出战槽位（开局带几件） | 2 件 | 3 件 | 4 件 |

> 这是**开局带进场**的件数。进关之后槽位不再是这个数 —— 局内靠三选一可以一路扩到 6 件（复玩 8 件），
> 见 [`四、七条成长线`](#四七条成长线不是双轨) 里的槽位说明。

远程怪比例还会随关卡进度再涨（第 1~2 关完全不加，之后每关 +0.25%，**封顶 +3%**）——
同一档难度下越靠后的关卡远程越多。**噩梦 42% + 关卡 +3% + 复玩加难最多 +6%** 会收敛到硬上限 **45%**；
普通 / 困难 加满所有加成也够不到 45%，所以"远程墙"只属于噩梦档。

### 为什么是「每关独立」而不是一条全局难度线

一条全局难度线会带来死循环：玩家在第 12 关卡住，唯一出路是变强，而变强又只能靠打第 12 关。
每关独立则不会：第 12 关打不过，可以去打第 11 关的困难难度 —— 那里既能练手，金币产出还更高，
是**平行可选项**而不是唯一出路。

### 难度只能靠"打过了"解锁

```
第 1 关：普通 → 通关 → 解锁困难 → 通关 → 解锁噩梦
```

顺序解锁保证玩家进入噩梦前，已经通过困难采集到足够的金币把局外等级升上去，
并且拿到了难度专属装备。**不存在"直接跳级被劝退"的路径。**

### 难度驱动能力扩张，不只是"怪更硬"

| 难度 | 解锁的东西 |
|---|---|
| 通关普通 | 冰晶球（关卡 2）、长枪（关卡 3）、飞刃（关卡 4）、巨镰（关卡 6）、手里剑（关卡 8）；出战槽位 3 件 |
| 通关困难 | 铁锤（关卡 3）、雷杖（关卡 5）、重炮（关卡 7）；出战槽位 4 件 |
| 通关噩梦 | 回旋轮（关卡 5）、光矛（关卡 9） |

（括号里的数字是**关卡门槛**——两个条件都满足才发放。所以铁锤要"关卡 3 且已通关困难"。）

多一件武器不是数值增长，而是**多一套瞄准方式同时生效**（前向挥砍 + 锁定射击 + 全屏横扫一起带）。

### 两层继承，两种成本

| 场景 | 是否继承 | 成本 | 原因 |
|---|---|---|---|
| 首次进入更高难度 | **默认继承** | 免费 | 高难度敌人血量 ×3.3、数量 ×1.6，不给继承纯属劝退 |
| 同一难度复玩 | 看激励视频 | 一次广告 | 此时玩家要的是"冲更高纪录"，带巅峰装备重来动机最强 |

## 三、武器：五种瞄准方式 × 十种打击形状（12 常规 + 6 高阶专属 = 18 把）

两个维度是**正交**的，所以组合出来的手感各不相同，而不是"伤害高低"的差别。

**瞄准方式**决定"打谁"：

| 瞄准方式 | 行为 | 玩家要做什么 |
|---|---|---|
| `FRONT` 前向 | 只打面朝方向，完全不索敌 | **必须走位对准**，转身才打得到背后 |
| `LOCK_ON` 锁定 | 锁住一个目标持续追踪 | 什么都不用做，弹道最稳 |
| `NEAREST` 最近 | 每次攻击取最近的敌人 | 什么都不用做，敌人换位时弹道会横跳 |
| `MOVE_DIR` 移动向 | 攻击方向 = 拖动方向 | 走哪打哪，可以主动指定方向 |
| `SCREEN_ROLL` 全屏 | 横扫整屏，不取方向也不索敌 | 什么都不用做，纯割草 |

`FRONT` / `NEAREST` / `LOCK_ON` 三者最容易混，区别在于：

- **前向**「我朝哪打哪」—— 可以故意打空，命中 100% 由走位决定
- **最近**「哪近打哪」—— 每帧重算，弹道会左右横跳
- **锁定**「锁住不放」—— 目标死了或跑出射程才换，弹道最稳

**打击形状**决定"打几个"，共十种：单体重击 / 远程单体 / 三连射 / 范围剑气（扇形） /
穿透直线 / 震荡波（环身） / 剑雨覆盖 / 连锁闪电 / 陨石轰击 / 全屏滚动。

### 武器一览

| 武器 | 瞄准 | 起点形状 | 解锁 | 一句话 |
|---|---|---|---|---|
| 铁剑 | 前向 | 单体重击 | 关卡 1 · 普通 | 必须走位对准，前端最稳的近战 |
| 短弓 | 锁定 | 远程单体 | 关卡 1 · 普通 | 最省心，锁住就不管了 |
| 冰晶球 | 最近 | 远程单体 | 关卡 2 · 普通 | 解放双手，但弹道会横跳 |
| 长枪 | 前向 | 穿透直线 | 关卡 3 · 普通 | 敌人排成一列时一枪串起整排 |
| 铁锤 | 移动向 | 单体重击 | 关卡 3 · 困难 | 走哪打哪，可以主动指定方向 |
| 巨镰 | 前向 | 范围剑气 | 关卡 6 · 普通 | 前向大扇形，被围住时一刀清一圈 |
| 飞刃 | 移动向 | 三连射 | 关卡 4 · 普通 | 极快攻速，边走边泼 |
| 雷杖 | 最近 | 远程单体 | 关卡 5 · 困难 | 越扎堆越强，连锁导电 |
| 重炮 | 锁定 | 远程单体 | 关卡 7 · 困难 | 射速极慢，一发要打准位置 |
| 手里剑 | 移动向 | 三连射 | 关卡 8 · 普通 | 跑动中铺满全场 |
| 光矛 | 锁定 | 穿透直线 | 关卡 9 · 噩梦 | 锁定后贯穿一条线 |
| 回旋轮 | 全屏 | 全屏滚动 | 关卡 5 · 噩梦 | 完全不瞄准，纯割草 |

> 解锁条件是「关卡进度 **AND** 难度进度」，两个条件都满足才发放 —— 见
> `EquipmentConfig.isEquipUnlocked()`。所以推进难度不只是怪更硬，而是实打实的能力扩张。
>
> 上表是 **12 把常规武器**。另有 **6 把高阶专属武器**（星刃 / 霜寒枪 / 疾风弓 / 震地锤 / 虚空炮 / 曜日轮），
> 不出现在关卡解锁里，只能从武器池抽到，且**直接以高阶品阶出生**（自带复合属性）——
> 所以 `EQUIPMENT_TABLE` 一共是 18 条、武器池也是 18。高阶专属的差异是"起点高 + 自带属性"，
> 不是"数值碾压"（抽到一样是 1 级）。

形态可以覆盖武器类型的默认瞄准方式，用来做「**终局形态 → 变全屏割草**」：

```
铁剑  铁剑·前向 → 淬锋剑/阔刃剑 → 裂空剑/环刃剑 → 天罚剑·全屏剑雨   ← 操作门槛逐级消失
铁锤  铁锤·移动向 → 重锤/阔锤   → 震地锤/裂地锤 → 陨星锤·全屏陨石
```

前期靠操作换强度，后期用强度换省心。

### 平衡靠什么守：有效输出预算

武器之间的强弱不能只看 DPS，因为"打不中"不是 DPS 能表达的：

```
有效输出预算 = DPS × 命中数(打击形状) × 瞄准可靠度(瞄准方式)
```

- **三连射的 DPS 要单独算**：`buildBullet` 对 `count > 1` 的攻击有 `damage × 0.62` 的衰减，
  实际是 `3 × round(单发 × 0.62) / interval`。漏算这一项曾让飞刃与手里剑冲到全表最高 DPS。
- **覆盖率的收益要按阵型打折**：`covEff = 1 + (cov - 1) × CLUMP[阵型]`，
  `CLUMP = { scatter: 0.25, line: 0.55, cluster: 1.0, swarm: 0.8 }` ——
  一个半径 200 的震荡波在扎堆关能打到 6 个，在散兵关只打到 1 个多一点。
- **间隔必须和打击形状一起看**：巨镰是 `SWEEP`（半径 = 射程 × 0.7、命中范围内全部）
  却只有 0.72s 间隔，在所有阵型都最优；把间隔拉到 0.95s、伤害 10→9 后才回到中游。
  同理光矛的 `LOCK_ON + 穿透 + 长射程` 是结构性优势，加了贯穿上限 3 并拉长间隔才压住。

这套模型写在 `balance_guard.js` 里当不变量守着（53 项），详见
[`docs/装备与进化设计.md`](docs/装备与进化设计.md) 的数值平衡章。

### 每关最合适的武器都不一样

每关有一个**阵型**，阵型既真的改变刷怪位置分布，也决定推荐/克制名单：

| 阵型 | 刷怪位置 | 推荐池 | 克制池 |
|---|---|---|---|
| 零散突进 | 四面八方零散出现，彼此离得远 | 铁剑 / 短弓 / 重炮 | 雷杖 / 巨镰 / 冰晶球 |
| 成列推进 | 倾向排成一列，前排挡住后排 | 长枪 / 光矛 / 冰晶球 | 巨镰 / 重炮 |
| 密集扎堆 | 挤成一团冲过来，越打越密 | 雷杖 / 巨镰 / 铁锤 / 冰晶球 | 重炮 / 短弓 |
| 人海散兵 | 数量多但各自为战，满场乱窜 | 飞刃 / 手里剑 / 回旋轮 / 铁锤 | 重炮 / 光矛 |

（池子是按"最合适 → 次合适"排序的候选，每关实际取其中**连续 2 件**，取哪两件由 `rot` 决定。）

- 阵型按 4 关一轮循环（`FORMATION_CYCLE`），**同一阵型内部的推荐名单还会按关卡序号轮转** ——
  同样是散兵关，第 1 关推近战、第 5 关推点射、第 9 关推炮击。玩家的最优解每关都在动。
- 代价与收益：带推荐武器 **伤害 ×1.25、金币 ×1.30**；带克制武器 **伤害 ×0.80**。
  刻意不做成"必须带"（硬克制会让泛用户卡关），而是"带了明显更爽"。
- 推荐与克制同时命中时互相抵消为 1.0 —— 想全吃加成，就得放弃另一把，这是刻意保留的搭配权衡。
- 判定按**形态所属武器线**追溯（`weaponRootIdsOf`）：玩家后期带的都是"剑雨风暴"这种合成形态，
  只比对根形态 id 会让加成在进化之后莫名消失，所以合成形态的 `sources` 也一起参与判定。

## 四、七条成长线（不是双轨）

装备与成长被拆成**七条互不重叠**的线。它们各自消耗不同的资源、改不同的东西，
所以不会互相抢位，也不会出现"点了这个就没法点那个"的死结。

| 成长线 | 在哪 | 消耗什么 | 占槽位吗 | 改什么 |
|---|---|---|---|---|
| **局外升级** | 主界面 EquipPanel / 锻造台 | 永久金币 `gold` | — | 武器**基础伤害**（无上限） |
| **突破等阶** | 锻造台 | 金币 + 该武器**专属**材料 | — | **镶嵌位数量**（1→4） |
| **属性镶嵌** | 锻造台 | 完整属性材料（碎片合成） | — | 该武器的克制关系与六条乘区 |
| **防具套装**（第九轮） | 许愿抽 → 锻造台穿戴 | 许愿水晶（抽）+ 金币/同阶防具（升阶）+ 水晶/材料（开槽镶石） | ❌ 独立四部位槽 | 属性**抗性** + 单件专属词条 + 套装属性 |
| **局内形态** | 局内三选一 | 这一局的升级机会 | ✅ 占武器槽 | 攻击形状 / 瞄准方式 / 伤害% |
| **辅助装备** | 局内三选一 | 这一局的升级机会 | ✅ 占辅助槽 | 攻速 / 暴击 / 吸血 / 护盾 / 反伤 / 弹道数 |
| **天赋** | 局内三选一 | 这一局的升级机会 | ❌ **不占任何槽** | 基础体质（可叠层） |

> **局外升级只吃金币，且完全支持"全给一把武器"**：
> 每件武器的等级独立计算、没有共享池、没有"必须均衡"的要求。
> 想当铁剑专精玩家就把钱全砸铁剑 —— 这是允许的，而且是刻意的。
> 突破等阶与属性镶嵌**不吃金币以外的东西**（材料全部靠打关卡掉落），
> 所以"只喜欢一把武器"的玩家有明确的独立成长线。
>
> **防具是"补上局外轴"而不是"再造一条武器轴"**：武器能做局外升级 → 升阶 → 镶嵌，
> 防具补齐了同等的深度（四部位穿戴 → 升阶 → 开槽 → 镶石），但走的是**抗性 + 词条**这条独立乘区，
> 不与武器的破防抢资源，四部位有自己的槽，也不挤占武器/辅助的局内槽位。

### 为什么局内形态不是"一条链"而是"一张图"

原来是每件装备一条线性链（stage 0→1→2→3），玩家没有任何选择权：拿到铁剑就注定变成天罚剑。
这带来两个问题：复玩时成长路径和第一遍一模一样；并且**无法表达"两把武器合成一把"**——
线性链里没有第二个输入。

改成形态图（`FormNode` + `EvolutionEdge`）之后，三类需求用同一套结构表达：

```
                 ┌─ 淬锋剑 ──→ 裂空剑 ──┬─→ 天罚剑 ──┐(★复玩)
铁剑 ─ depth 0 ─┤                       │             ↘
                 └─ 阔刃剑 ──→ 环刃剑 ──┴─→ 斩星剑    创世刃  (depth 4)
   ↑ 两条分支（单点爆发 / 范围覆盖），由玩家在 depth 1 选
   ↑ depth 3 各线收束为全屏形态
   ↑ depth 4 标 advanced 的边**只在携带老档复玩时出现**
```

**三类进化行为差异**（这是玩家需求里最容易被做混的一段）：

| 类型 | 槽位 | 说明 |
|---|---|---|
| **升级型** `upgrade` | **数量不变** | 同一槽内换形态。辅助装备的进化**全部**是这一类 —— 玩家原话"这种就不会消失辅助装备" |
| **合成型** `fusion` | **消耗一个武器槽** | 材料 A + 材料 B 两个槽 → 产物一个槽，数组长度 −1 |
| **复玩限定** `advanced` | 沿用上面规则 | 边上的 `advanced = true`，`carrySource !== 'none'` 时才出现 |

**合成后可以立刻补选一件武器**：`RunLoadout.applyFusion()` 把 `pendingPicks += 1`，
`LevelFlow` 会在同一帧再开一次三选一面板，标题写明「合成消耗了一个武器槽 · 补选一件武器」。
不补这一步玩家会觉得"合成是在惩罚我"。

**合成不会亏**：合成形态的 `sources` 是两件材料武器的局外装备 id 列表，
`baseDamageOfForm(sources)` 按 sources 求和 —— 铁剑 + 短弓合成后，**一格里吃两把武器的局外等级收益**。
否则理性的玩家永远不会选择合成。

### 局内形态的经验与等级

每个槽**独立**累积经验，经验决定它的形态等级（1~3 级，`FORM_LV_EXP = [0, 110, 260]`）。
等级满了才 `ready`，三选一里才会出现它的进化选项 —— 这就是玩家说的"升级成功然后进化"。
每提升 1 级形态等级额外 +10% 攻击。

形态达成后还需要该条线累积够进化经验才能跨 depth（`DEPTH_EXP_NEED = [90, 190, 340, 620, 980]`），
depth 越大门槛越高，终局进化必须打满一局才能摸到。
`carryExpOver(exp, fromDepth)` 会扣除门槛、把**溢出经验带到下一层**，所以不会浪费。

刻意压得低：一局正常打能升满 1~2 个槽，想升满全部槽必须带着继承进来的等级复玩 —— 这正是复玩的动力。

### 槽位：基准 6/6，复玩 +2

```
武器槽  基准 6  ─┐
辅助槽  基准 6  ─┴─ 携带老档复玩时各 +2  → 8 / 8
```

做成"复玩加成"而不是直接提高基准，是因为：首次开荒时槽位少，玩家的每一次三选一都是**取舍**
（要不要换掉现有武器）；槽位多了之后取舍变松，是复玩才配得上的松弛感。
如果基准就是 8，首局也会变成"全都拿着"，选择就没有重量了。

> ⚠️ 两套槽位数字不要搞混：`getEquipSlotCount(tier)` = **开局带几件武器进场**（2/3/4，由难度解锁）；
> `weaponSlotCap(replay)` = **一局内最多能持有几件**（6，复玩 8）。前者是起点，后者是天花板。

### 局内固定三选一

打怪攒经验升级 → 弹出**固定三张卡**。主类别按等级取模轮转（`rewardFocusFor(level)`），
主类别出 2 张、其他类别补 1 张：

| 升级到 | 主类别 | 出卡 |
|---|---|---|
| Lv.2 | 武器 | 武器 ×2 + 天赋 ×1 |
| Lv.3 | 天赋 | 天赋 ×2 + 辅助 ×1 |
| Lv.4 | 辅助 | 辅助 ×2 + 武器 ×1 |
| Lv.5 | 武器 | …循环 |

- **用轮转而不是随机**：随机会出现连续三次都是辅助装备的情况，轮转保证"最多隔一次就轮到武器"。
- `FOCUS_OFFSET = 1` 让**第一次三选一（升到 Lv.2）落到武器档** ——
  否则 `2 % 3 = 2` 会落到辅助档，玩家开局第一张卡是件辅助装备，完全感受不到"武器会进化"这个核心。
- **天赋不占槽位是刻意的**：它是三选一里的**保底项**。抽到武器可能因为槽满而没用，
  抽到进化可能条件没到，但天赋永远能拿 —— 于是三选一永远不会出现"三个都点不了"的死屏。
- 补齐阶段必须 `if (k === focus) continue;`，否则主类别会被同一类别重复占位。

### 战力计算

```
baseDamage  = Σ 出战装备的局外基础伤害（合成形态按 sources 求和）
finalDamage = baseDamage × (1 + Σ 形态攻击%) × (1 + Σ 天赋/辅助攻击%) × 关卡适配倍率
rangeMul    = 1 + Σ 形态距离% + Σ 天赋距离%
interval    = 武器基础间隔 ÷ (1 + 攻速%)
```

完整说明见 [`docs/装备与进化设计.md`](docs/装备与进化设计.md)。

## 六、接入步骤

1. **建工程**：Cocos Creator 3.8 新建 2D 空项目，把 `assets/scripts` 整个目录拷进工程的 `assets/` 下，等待编译。
2. **搭场景**：按各脚本头部注释里的节点树搭 UI。除 `EquipPanel` 自己管理显隐外，其余面板
   （LevelSelect / Difficulty / Loadout / BattleLayer / Result / Reward / ReplayEnhance / Tree / Achievement / Forge）
   初始 `active = false`，由 `GameEntry.syncLayerByPhase()` 统一控制 —— 战斗层**只在 PLAYING 与 REWARD** 显示
   （`REWARD` 时面板盖在战场上，因为战斗是冻结的；`REPLAY_BOOST` 是进关前的阶段，不能显示上一关的残留战场）。
3. **配战场**：`BattleLayer` 节点下建一个 `Arena` 空节点，加 `Graphics` + `UITransform`，尺寸设成 **720 × 1280**（设计分辨率即战场尺寸）。再建一个同尺寸的 `InputArea` 节点加 `DragInput` 组件。`Arena` 不需要任何美术资源，Graphics 会把背景、角色、敌人、弹道、血条全部画出来。
4. **挂组件**：`GameEntry` 挂 Canvas 空节点，把各 Label / Node / 组件引用拖进属性面板（**别忘了新增的 `rewardPanel` / `replayEnhancePanel` / `treePanel` / `achievementPanel` / `forgePanel` / `counterPanel`**）。
   - `counterPanel` 挂在战场角落（三个 Label），**24 种属性下不可省** —— 玩家不可能背 24×24 的克制表
   - `difficultyPanel` 的 `elementLabel` 用来显示"本关怪物属性"，同样不可省
   - **教学覆盖层不用手动搭节点**：`TutorialLayer` 第一次用到时由 `TutorialLayer.ensure()` 自己
     建 Canvas 子节点、挂 `Graphics` + `Label` 并画出来（和 `BattleLayer` 一样零美术）。
     引导与首通提示都由 `GameEntry` 触发，没有需要在编辑器里连的引用
   按钮事件已在 `onLoad` 里用代码绑定，不需要在编辑器里再连一次。
5. **填广告位**：替换 `AdReward.ts` 里的 `AD_UNIT_IDS`（微信公众平台 → 流量主 → 广告位管理创建）。
6. **改盐值**：替换 `HashUtil.ts` 里的 `SALT`，换成自己的随机串，不要提交到公开仓库。
7. **构建**：构建平台选「微信小游戏」。`game.json` / `game.js` 由 Cocos 自动生成，无需手写。

> 老工程升级：存档会自动从 v1 一路迁移到 **v8**（旧键 `mg_archive_3` → `mg_archive_3_1`；
> v3 把旧的 `(装备 id, stage)` 反查成新的 `formId`；v6 把 `forge.rank` 吸收进品阶；
> v7 把单表防具改成四部位 `ArmorWorn` + uid 实例模型，并补上 `tutorials` 教学标记；
> v8 补上 `omni` 万象线进度字段，**只补结构、不白送任何资源**），
> 老玩家的通关记录、最高分、装备等级一条不丢，见 `SaveManager.migrateToV2()` … `migrateToV8()`。

## 七、战斗层怎么接

战斗层与装备系统的接口只有两个纯数据，双方互不认识对方的内部结构：

```ts
// 1. 开打前，把装备翻译成每件武器的战斗参数
const weapons = EquipmentManager.buildWeapons(state.equipment, state.stats);
// → WeaponSpec[]：{ 名称, 瞄准方式, 攻击形状, 伤害, 打击尺度, 攻击间隔, 贯穿上限 }

// 2. 交给战斗层开打（cfg 已按难度缩放好）
battle.begin(cfg, weapons, state.stats.hp, {
    onEnemyKilled: () => LevelFlow.inst.onEnemyKilled(),  // 加分/掉资源/涨经验全自动
    onCleared:     () => onBattleWin(),
    onDefeat:      () => onBattleLost(),
});

// 3. 形态进化发生时把新参数推过去 —— 当场生效
LevelFlow.inst.onEvolve(() => {
    battle.syncWeapons(EquipmentManager.buildWeapons(state.equipment, state.stats));
});
```

辅助装备与天赋不进入 `WeaponSpec`，它们叠成一份 `CombatModifier`（攻速 / 暴击 / 吸血 / 护盾 / 反伤 /
弹道数 / 移速…），由 `battle.setModifier()` 下发。护盾与荆棘走 `setup` 而不是逐帧加成，
因为它们只该在"受到伤害"这一刻结算一次。好处是 **新增一件辅助装备要动的只有数据表，战斗逻辑一行不改**。

想只替换玩法、保留难度与存档系统？只改 `battle/` 里的四个文件即可，`ui/BattleLayer.ts` 换成你自己的渲染层。

## 八、广告触发点（按转化率排序）

1. **结算面板的「看视频 · 带装备重刷本难度」** —— 玩家刚通关、情绪最高点，动机最强。直接调 `startWithCarry()` 开局。
2. **难度选择 → 点已通关的难度** —— 弹 `LoadoutPanel`，逐件列出"铁剑 · 裂空剑（攻击 +160% · 前向）"，让玩家看得见能省下多少成长。
3. **关卡内复活 / 结算翻倍** —— 可选，`AdTag` 已预留枚举位。当前战败走的是无惩罚自动重开，如果改成"看广告原地复活"，转化率通常比结算翻倍更高。

**注意**：首次进入更高难度的默认继承**不是广告位**，是游戏机制。把它做成广告位会让难度推进变成付费墙。

三处广告都遵守同一套约束：**必须保留不看广告的免费路径，广告只能在玩家点击后播放，广告未播完绝不做任何数据变更。**

## 十一、性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首屏时间 | ≤ 3s | 小游戏审核红线是 5s |

| DrawCall | ≤ 50 | 当前 Graphics 方案全场 1 个 DrawCall |

两个性能注意点：

- **战场渲染**用的是单个 `Graphics` 逐帧重绘（`clear()` + 画全部对象）。噩梦难度敌人 10~13 只完全没问题；要做到上百敌人，换成对象池 + Sprite 合批。
- **关卡选择列表**不要一次性实例化全部按钮，`LevelSelectPanel` 默认只铺到「已解锁 + 2」关，需要更多时改成 `ScrollView` + 对象池。

## 十四、调试

`GameEntry` 上留了这些调试方法，可直接在编辑器里点：

- `debugClear()` —— 强制通关当前难度（触发结算、写档、解锁下一难度、判成就）
- `debugResetCurrent()` —— 本局数据清零重开（档案保留）
- `debugUnlockTier(levelId, tier)` —— 解锁某关某难度，验证难度面板、开局槽位与装备开放
- `debugFeedExp(amount)` —— 灌经验，快速验证三选一与"形态进化当场生效"
- `debugOpenReward()` —— 直接弹出一次三选一面板（`debugFeedExp(100000)` 的快捷方式）
- `debugReplayBoost(percent)` —— 直接带加难百分比开局，验证复玩加难链路
- `debugAddGold(amount)` —— 发永久金币，测试局外升级
- `debugBattle()` —— 打印战斗层快照（血量、武器冷却与锁定、敌人与判定体数量）
- `debugDump()` —— 控制台打印全部存档（`mg_archive_<关卡>_<难度>` 全量，含成就与图鉴）

主界面的「进化图鉴」与「成就」按钮在战斗中被点击时只会弹一句 toast
（`战斗中无法查看图鉴/成就`），不会真打开面板 —— 这两块面板属于局外，战斗里打开会遮住战场。

`LevelFlow.resetArchive(levelId, tier?)` 是唯一的真正清档入口（不传 tier = 清掉该关所有难度），
已接到 `LevelSelectPanel.onResetLevel()`。
