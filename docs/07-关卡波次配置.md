# 07 · 定时关卡波次配置

当前规则于 2026-10-18 替代 24 只/6 批方案：每局 3 波，每波 30 秒，波内持续每秒补怪。普通首关每秒 12/16/20 只，对应未限流预计 360/480/600 只；同屏上限 240。满屏跳过该次生成，不积压，也不把预计数量当作通关击杀门槛。90 秒后停止生成，清理存活敌人后通关。

波内怪物生命和攻击固定，换波时按生命 1/1.25/1.5、攻击 1/1.15/1.3 调整，同一波的远程/冲锋不额外提升攻防或护盾。行为、速度和属性仍可不同，普通前两关没有远程。

配置入口：assets/scripts/data/EncounterConfig.ts；LevelConfig 与 tools/generate-wave-plan.mjs 共用规则。BattleWorld 已通过 EnemySpawnSpec.waves 接入定时投放。运行时不直接读取规划 JSON。

执行 node tools/generate-wave-plan.mjs，生成 200 关 × 3 难度共 600 份 JSON 和经验 CSV。JSON schemaVersion=3，waves 包含 startSec、durationSec、spawnIntervalSec、spawnCount、hpMul、atkMul、maxAlive 和 continuous。entries.count 及 summary.totalEnemies 为无限流预计值；类型数量为配置比例估算，实际按 ID 确定性抽取，不承诺与估算完全相等。经验按实际每杀角色 2、装备 3 发放，经验加成仍生效并保留小数；普通首关基础估算升级 14 次。

暂停选卡不计时；续玩存活怪满血重建，投放 ID 和波次进度恢复。完整位置、弹道、血量快照、微信真机 240 怪性能及高关卡平衡仍需验证。
