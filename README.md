# 武器收集 Roguelite · 微信小游戏

Cocos Creator **3.8.8 + TypeScript**。拖动走位、自动攻击、局内三选一、武器强化进化、局外装备养成与关卡继承。最后整理：**2026-10-18**；永久存档版本 SAVE_VERSION = 8。

## 当前玩法

- 每局 **3 波 × 30 秒**，波内持续补怪，选卡暂停不计时。普通首关每秒投放 12/16/20 只，未限流估算 360/480/600 只；同时存活上限 240，满屏跳过投放，不积压。90 秒后停止出怪，清理剩余敌人才通关。
- 同波怪物生命和攻击一致，保留移动及远程/冲锋行为差异，不生成精英护盾怪。普通前两关没有远程；密集波次玩家受击保护为 0.35 秒。
- 每杀基础角色经验 **2**、装备培养经验 **3**，角色升级门槛为 70 + 20 × (等级−1)。普通首关全击杀基础估算升级 14 次；经验加成保留小数，实际次数由击杀和加成决定。
- 武器当前形态必须选择 **5 次强化**，再持有配套辅助，才能在三选一中进化。每次强化增加 15% 攻击加成，进化保留收益和辅助，新形态重新累计强化。配对表和合成规则见 [局内成长](docs/02-局内成长.md)。
- 击杀逐只结算并去重；跨级奖励逐级排队；最后一击的升级奖励领取完再结算通关。选卡的武器、辅助、天赋属性立即同步战斗。
- 战败显示本局收益，可选择广告复活继续、保留成长重试、返回选关，不再自动重开。复活恢复波次，重试回第一波；已发过奖励的敌人 ID 不重复发奖。返回选关放弃本局临时收益。
- 波次、成长、待选卡和奖励队列可续玩；存活怪物满血重建，尚不恢复坐标、当前生命、弹道及冷却。旧档保留成长，无需清档。

原有三档难度、18 条武器线、14 条辅助线、24 属性、92 件防具、三池抽卡、锻造与关卡继承继续沿用对应模块规则。六把高阶专属武器仍无额外进化路线。

## 打开与验证

1. 安装依赖：npm ci（保留 package-lock.json）。
2. 用 Cocos Creator 3.8.8 打开项目，等待资源导入，打开 assets/scenes/Main.scene 后预览。
3. 执行适用检查：

```sh
npm run typecheck
npm test
npm run assets:check
npm run typecheck:cocos
npm run calibrate
```

typecheck 使用独立逻辑类型桩；typecheck:cocos 依赖编辑器生成的 temp/tsconfig.cocos.json 和真实引擎类型，首次打开工程前不能直接执行。calibrate 输出模型与战斗模拟偏差，执行成功不代表平衡验收通过。

当前 11 个测试套件覆盖资源身份、形态、品阶、属性、存档、教学、平衡、3000 组经验配置、局内流程、定时波次和五次强化进化。它们不能替代编辑器、微信工具或真机验收。

**最新状态**：逻辑测试、两类类型检查与 64/64 资源检查通过；首关逻辑模拟可完成三波与强化进化。今天早期版本已验证浏览器预览及 Web/微信导出；最新玩法仍受编辑器旧脚本缓存影响，尚未完成最新预览与重新构建。保存场景后重开工程、等待全部导入再预览。微信开发者工具、Android/iOS 真机和 240 只同屏性能未验证；正式 AppID、广告位仍未配置，未提审或发布。详细证据见 [工程与验证](docs/13-Cocos工程与验证.md)。

## 工程与配置

| 路径 | 用途 |
|---|---|
| assets/scripts/battle/ | 纯战斗逻辑，只接收 WeaponSpec/BattleSetup 等数据 |
| assets/scripts/core/ | 对局、成长、存档、装备和奖励业务 |
| assets/scripts/data/ | 类型、数值与配置；定时波次入口 EncounterConfig.ts |
| assets/scripts/ui/ | 展示和输入；GameEntry.ts 连接业务与战斗 |
| assets/scenes/、assets/prefabs/、.meta | 启动场景、预制体与稳定资源身份 |
| configs/levels/ | 600 份波次规划 JSON 与经验 CSV，数量为未限流估算 |
| tools/generate-wave-plan.mjs | 共用运行时规则重新生成规划 |
| extensions/game-project-tools/ | 场景与预制体维护扩展 |
| configs/build/ | Web/微信构建模板；微信 AppID 保持空值待真实配置 |

提交源文件、场景、预制体、配置、资源标识和验证工具；依赖、引擎缓存、构建目录、临时验证脚本及日志不进入版本库。
